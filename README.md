Training: [Build your first end-to-end test with Playwright](https://learn.microsoft.com/en-us/training/modules/build-with-playwright/)
Skills: Beginner, Developer, Microsoft Playwright Testing, Visual Studio Code
Summary: In this training, we learned how to use Playwright to test a sample web application. We learned how to run tests, view test reports, and understand the structure of a Playwright project. We also learned how to use Visual Studio Code to run tests, debug tests, and record new tests.
Learning Objectives:
- How to use Playwright to test a sample web application.
- How to run tests, view test reports, and understand the structure of a Playwright project.
- How to use Visual Studio Code to run tests, debug tests, and record new tests.
Prerequisites:
- Visual Studio Code
- node
- npm

- Introduction
- What is Playwright?
- Exercise: Getting Started with Playwright

- Understand Test Specification
- Exercise: Using Playwright in Visual Studio Code

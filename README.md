## 📝 Summary

 In this training, we learned how to use Playwright to test a sample web application. We learned how to run tests, view test reports, and understand the structure of a Playwright project. We also learned how to use Visual Studio Code to run tests, debug tests, and record new tests.

---

## 🎓 Learning Objectives

✅ How to use Playwright to test a sample web application

✅ How to run tests, view test reports, and understand the Playwright project structure

✅ How to use Visual Studio Code to run tests, debug tests, and record new tests

---

## ✅ Prerequisites
